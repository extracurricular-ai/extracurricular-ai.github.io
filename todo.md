# ExAI Todo

## Initiatives feature

Consider adding an initiatives section to the site to give the community structured on-ramps and things to rally around.

**Top candidates to start with:**
- **Ship in a Weekend** — pick a theme (agents, RAG, voice, etc.), everyone builds something small and shares it
- **Demo Days** — regular async showcase where members share what they built, no polish required

**Other ideas in the backlog:**
- "Replicate it" — take a recent AI paper or closed product and build an open version together
- "AI from Scratch" — a structured beginner track guided by the community
- "Read the Docs" — go deep on a specific tool/framework together each month
- "Smallest Useful Agent" — build the most useful thing with the fewest lines of code
- "No API Keys" — build something meaningful using only open/local models
- "Open Office Hours" — recurring time where experienced members help newcomers get unstuck

**Implementation notes:**
- Start lightweight — a section on the homepage or Get Involved page, not a full separate page
- Only add if there's commitment to actually running them (a dead initiatives page hurts more than helps)
- Initiatives naturally generate blog content
